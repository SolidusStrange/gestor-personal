# Iconos / pixel art

Cuando agregues assets de pixel art, colócalos aquí. Usa nombres estables (por ejemplo `quest-check.png`, `star-1.png`, `star-5.png`, `mission.png`) y conserva una copia de la licencia/atribución del paquete descargado. En HTML se utilizarán con `<img src="assets/icons/archivo.png" ...>` y en CSS con `image-rendering: pixelated` para conservar los píxeles.
